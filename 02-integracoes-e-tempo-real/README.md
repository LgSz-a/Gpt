# Integrações e tempo real

Referências para receber eventos de plataformas externas e transmitir atualizações em tempo real.

## Referências

- [TikTok LIVE Connector](https://github.com/zerodytrash/TikTok-Live-Connector)  
  Biblioteca Node.js não oficial para receber comentários, presentes, curtidas, seguidores, compartilhamentos e outros eventos de lives.
- [Socket.IO](https://github.com/socketio/socket.io)  
  Biblioteca para comunicação bidirecional em tempo real entre cliente e servidor, com eventos e reconexão.

## Atenção

O TikTok LIVE Connector informa que é um projeto de engenharia reversa e não é uma API oficial nem uma solução pronta para produção. Mudanças internas do TikTok podem interromper seu funcionamento. Para o Torcida.gg, avalie disponibilidade, limites, estabilidade e alternativas antes de depender dele.
