# Jogos multiplayer

Referências para arquitetura de jogos online, servidores autoritativos, salas e sincronização de estado.

## Referências

- [Colyseus](https://github.com/colyseus/colyseus)  
  Framework multiplayer autoritativo para Node.js, com gerenciamento de salas e SDKs para diferentes plataformas.
- [Multiplayer Game Backend](https://github.com/Serkanbyx/multiplayer-game-backend)  
  Exemplo de plataforma multiplayer com WebSockets, salas, matchmaking, espectadores, chat e ranking, usando React, Express, Socket.IO, PostgreSQL e Redis.
