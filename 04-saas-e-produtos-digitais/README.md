# SaaS e produtos digitais

Referências para estudar arquitetura e componentes comuns de produtos SaaS.

## Referências

- [Wasp - Open SaaS](https://github.com/wasp-lang/open-saas)  
  Template open source para iniciar aplicações SaaS, com stack baseada em React, Node.js e Prisma, além de recursos de autenticação, pagamentos e administração.

## Como aproveitar

Use como referência de arquitetura e comparação de decisões técnicas. Não adote um starter kit inteiro sem entender autenticação, permissões, pagamentos, banco de dados, deploy e manutenção.
