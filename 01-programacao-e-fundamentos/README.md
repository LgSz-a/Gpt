# Programação e fundamentos

Materiais para aprender desenvolvimento web e construir uma base técnica.

## Referências

- [Microsoft - Web Development for Beginners](https://github.com/microsoft/Web-Dev-For-Beginners)  
  Curso estruturado de 12 semanas, com HTML, CSS e JavaScript, exercícios e projetos práticos.
- [The Odin Project - Curriculum](https://github.com/TheOdinProject/curriculum)  
  Currículo open source de desenvolvimento full-stack, com aulas e projetos para portfólio.
- [freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp)  
  Plataforma de aprendizado com desafios interativos e trilhas de desenvolvimento web, JavaScript, Python, banco de dados e APIs.

## Ordem sugerida

1. Consolidar HTML e CSS.
2. Aprender JavaScript e manipulação do DOM.
3. Fazer projetos pequenos sem copiar soluções prontas.
4. Avançar para backend, APIs e banco de dados.
5. Construir e publicar projetos próprios.
