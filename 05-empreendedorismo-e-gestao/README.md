# Empreendedorismo e gestão

Materiais para estudar criação, validação e crescimento de negócios.

## Referências

- [Awesome Startup Resources](https://github.com/eferrares/awesome-startup-resources)  
  Lista de recursos sobre validação, descoberta de clientes, produto, métricas, captação, ferramentas e operação de startups.
- [Awesome CEO](https://github.com/kuchin/awesome-ceo)  
  Curadoria de conteúdos para fundadores e líderes, incluindo fundraising, empreendedorismo, produto, vendas, marketing, gestão, contratação e finanças.

## Como aproveitar

Priorize materiais que ajudem a tomar decisões concretas: conversar com clientes, medir retenção, entender aquisição, controlar custos e testar hipóteses. Consumir conteúdo sem executar é só procrastinação com uma bibliografia bonita.
