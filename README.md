# Gpt

Repositório central de referências para programação, desenvolvimento do Torcida.gg, criação de produtos digitais, empreendedorismo, segurança e legislação.

A ideia é manter os materiais organizados por finalidade. Este repositório funciona como um **índice de estudos e referências**: os projetos originais continuam nos repositórios de seus respectivos autores.

## Como usar

1. Abra a pasta do assunto que está estudando.
2. Leia o README da pasta para entender o que cada referência oferece.
3. Consulte a documentação oficial do projeto antes de implementar algo.
4. Confira licença, manutenção, compatibilidade e limitações antes de usar código em produção.

## Relação com o repositório Invest

Materiais de educação financeira e investimentos ficam separados no repositório **[Invest](https://github.com/LgSz-a/Invest)**. Isso evita misturar estudos de programação e negócios com a biblioteca de investimentos.

## Cuidados

- Um repositório listado aqui não é automaticamente seguro, atualizado ou adequado para produção.
- Projetos não oficiais ou de engenharia reversa podem quebrar sem aviso.
- Confira a licença antes de reutilizar código. Alguns projetos permitem uso apenas sob condições específicas.
- Em temas jurídicos, use as fontes oficiais e confirme a redação vigente da norma. Um repositório de legislação é ferramenta de pesquisa, não substituto de validação jurídica.
